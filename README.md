# Clínica Sabrina 💗

Site institucional da Clínica Sabrina, desenvolvido com HTML e CSS, com foco em apresentar a clínica, destacar suas especialidades e facilitar o agendamento de consultas pelo WhatsApp.

## 📋 Sobre o projeto

O projeto consiste em uma página web responsiva para divulgação da clínica, com uma interface visual em tons de rosa, apresentação inicial, seções de especialidades e links para contato.

## ✨ Funcionalidades

- Apresentação da Clínica Sabrina.
- Seção de destaque com chamada para agendamento.
- Área para apresentação de especialidades.
- Botões para agendamento de consultas pelo WhatsApp.
- Atalho flutuante do WhatsApp para facilitar o contato.
- Layout responsivo para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura e conteúdo da página.
- **CSS3:** estilos, layout, efeitos visuais e responsividade.
- **Google Fonts:** tipografia personalizada.
- **WhatsApp:** canal externo para contato e agendamento.

## 🚀 Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/Gabriel-VieiraC/clinica.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd clinica
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor backend para visualizar a página estática.

## 📱 Agendamento pelo WhatsApp

Os botões de agendamento direcionam o visitante ao WhatsApp com uma mensagem previamente preenchida.

**Importante:** antes de publicar o site, verifique se o número configurado nos links `wa.me` corresponde ao contato oficial da clínica.

## 📱 Responsividade

O arquivo `estilo.css` contém regras de mídia (`@media`) para adaptar elementos como o cabeçalho, a seção principal, as imagens e os blocos de especialidades a telas menores.

## 🔒 Segurança

Este projeto é uma página institucional estática. A implementação atual não inclui sistema próprio de autenticação, cadastro de usuários, gerenciamento de sessões ou emissão de tokens.

Caso sejam adicionadas funcionalidades para gerenciar pacientes, consultas privadas ou informações médicas, será necessário implementar um backend com autenticação e controle de acesso adequados.
